第一次使用？连接自己的订阅
  1. 在这台电脑安装 Codex，并使用自己的 ChatGPT 账号登录。终端可运行 codex login，选择 ChatGPT 登录。
  2. 在 Luna 项目目录运行 npm run install-service，启动本机后台并生成已配对扩展。
  3. 浏览器加载后台生成的 ~/.local/state/workbench/luna-translate/extension，然后点“重新检测”。

当前是“浏览器扩展＋本机后台”的本地版，安装器支持 macOS，需要 Node.js 22 或更新版本。单独安装未配对扩展还不能连接订阅；每位用户需要自己的后台与 Codex 登录。扩展不接收 ChatGPT 密码、登录 Token 或 API Key。

缓存与空间

LOCAL ONLY
—连接后显示实际占用
有明确容量上限

占用按序列化大小估算，保存时的临时文件最多另占同等空间。自动恢复的页面记录保留 30 天，译文按所选期限继续可复用。同时最多保留 1 万个片段。先达到时间、条数或空间限制就会清理；空间满时优先淘汰较久没读的结果。读缓存不使用模型额度。

清空会移除本机缓存和本浏览器的重读记录，不影响 Codex 登录、连接码与偏好。其他已显示的译文刷新后消失。
